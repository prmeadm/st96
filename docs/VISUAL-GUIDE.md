# ST96 — визуальные гиды

Бренд ST96 один на весь проект, но интерфейсы разные, поэтому гид разрезан
по папкам проектов: правила лежат рядом с кодом, который они описывают.

| Где | Что описывает | Файл |
| --- | --- | --- |
| Сайт `st96.by` | главная, услуги, `/en`, лендинги-витрины | [`site/VISUAL-GUIDE.md`](../site/VISUAL-GUIDE.md) |
| CRM | админка `/admin` и запись на встречу `/book` | [`crm/VISUAL-GUIDE.md`](../crm/VISUAL-GUIDE.md) |
| Бренд и печать | логотип, аватары, визитки, флаер | [`brand/README.md`](../brand/README.md) |
| Общее для сайта и CRM | `shared/ui` (`PhoneField`), тексты и данные | `shared/` |

## Общая основа (одна на все проекты)

- Шрифты: **Unbounded** (заголовки) + **Inter** (текст). Новых шрифтов не вводим.
- Ядро палитры: `ink #09090b`, `paper #f5f4ef`, `acid #d8ff3f`,
  акценты `violet #8b6bff`, `pink #ff5fa8`, `cyan #35e6c8`, `blue #4d7bff`,
  `orange #ff8a3d`.
- Правило: новый цвет, шрифт или радиус **не вводим**. Нужного не хватает —
  сначала добавить токен в CSS своего проекта, потом использовать.
- Источник правды — CSS, а не этот документ: `site/src/index.css`,
  `crm/admin/admin.css`, `crm/book/book.css`.
- Эмодзи в интерфейсе не используем; в боте допустимы умеренно.
- Русский — основной язык, английский — параллельный текст, не автоперевод.

Единый гид от 2026-10-31 разнесён на два гида по проектам без потери правил;
исходная версия осталась в истории git.
