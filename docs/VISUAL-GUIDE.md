# ST96 — визуальный гид (design system)

> Составлено 2026-10-31 по коду репозитория (не по памяти): `site/src/index.css`,
> `crm/admin/admin.css`, `crm/book/book.css`, `site/index.html`, `site/public/fonts`.
> Назначение: любая новая работа (сайт, админка, `/book`, письма, бот, лендинги
> вроде памятки стенда и видео-страниц) должна попадать в этот стиль без
> дополнительных вопросов владельцу.

## 1. Источник правды

| Что | Где |
| --- | --- |
| Токены цвета/шрифта/анимаций сайта | `site/src/index.css` (`@theme`, `:root`, `:root[data-theme='light']`) |
| Токены админки | `crm/admin/admin.css` |
| Токены записи на встречу | `crm/book/book.css`, `crm/book/fonts.css` |
| Шрифты (самохостинг) | `site/public/fonts/*.woff2` (`unbounded-cyrillic/latin`, `inter-cyrillic/latin`) |
| Фавикон, og-картинка | `site/public/favicon.svg`, `site/public/og-image.png` |
| Эталонные экраны | `site/src/components/` (hero, marquee, tabs, lead), `crm/admin/` |

Правило: новый цвет, шрифт или радиус **не вводим**. Нужного не хватает →
сначала добавить токен в `index.css`, потом использовать.

## 2. Палитра (тёмная тема — основная)

| Токен | Значение | Роль |
| --- | --- | --- |
| `--color-ink` | `#09090b` | фон страницы |
| `--color-ink-soft` | `#111114` | карточка, панель |
| `--color-ink-line` | `#232328` | границы, разделители |
| `--color-paper` | `#f5f4ef` | основной текст на тёмном |
| `--color-paper-dim` | `#a6a6ac` | вторичный текст, подписи |
| `--color-acid` | `#d8ff3f` | главный акцент: CTA, активные состояния |
| `--color-violet` | `#8b6bff` | акцент «продюсирование» |
| `--color-cyan` | `#35e6c8` | акцент «продакшн» |
| `--color-pink` | `#ff5fa8` | акцент «бьюти/ретушь», декор |
| `--color-blue` | `#4d7bff` | служебный синий (ссылки, инфо) |
| `--color-orange` | `#ff8a3d` | предупреждения, редкие акценты |
| `--color-acid-solid` | `#d8ff3f` | фон твёрдых кнопок — **не меняется** в светлой теме |
| `--color-on-solid` | `#09090b` | текст на твёрдой кнопке — **не меняется** в светлой теме |

Акценты услуг: `--accent-producing #8b6bff`, `--accent-promotion #d8ff3f`,
`--accent-production #35e6c8`, `--accent-ai #c084fc` — эти четыре темнеют в
светлой теме, потому что ими пишут текст на светлом фоне.

Фон твёрдых кнопок берётся не из них, а из постоянных `--accent-*-solid`
(в коде услуги — `accent.btn`). Правило: **кнопка не меняет цвет при смене
темы** — она остаётся того же цвета, что и в тёмной.

## 3. Светлая тема

Токены инвертируются целиком (`:root[data-theme='light']`), а не подменяются
вручную по месту:

- `ink` → `#f5f4ef`, `ink-soft` → `#ffffff`, `ink-line` → `#dad9d0`,
  `paper` → `#09090b`, `paper-dim` → `#585860`.
- `acid` темнеет до `#4f7600`, остальные акценты — тоже в более тёмный вариант
  (`#6246e0`, `#0a8472`, `#8a35dc`), иначе на светлом не читаются.
- Тема хранится в `localStorage['st96-theme']`, применяется inline-скриптом до
  первой отрисовки (без вспышки), переключение — класс `theme-anim` ~300 мс.
- Новый компонент обязан работать в обеих темах: цвет только через токены.

## 4. Типографика

- Заголовки — **Unbounded**, 400–900. Основная витрина: 600–800.
- Текст — **Inter**, 400–700.
- `--font-display: "Unbounded", "Inter", system-ui, sans-serif`;
  `--font-body: "Inter", system-ui, sans-serif`.
- Заголовки: крупно, плотный трекинг, обычно `text-balance`; длинные заголовки
  не переносим вручную через `<br>` — пусть переносит браузер.
- Подписи/эйрбрау: Inter 12–13 px, `--color-paper-dim`, часто uppercase с
  разрядкой.
- Сайт исторически тянет эти же шрифты с Google Fonts в `site/index.html`;
  локальные копии лежат в `site/public/fonts` (там их использует и `/book`).
  Правильное направление — перейти на локальные (меньше запросов, нет
  зависимости от внешнего сервиса, стабильнее в RU).

## 5. Форма и ритм

- Радиусы: карточки и панели — умеренные (12–20 px), кнопки — pill или 12 px;
  острых углов на сайте нет.
- Границы — 1 px `--color-ink-line`; тени почти не используются, объём даётся
  контрастом фона и границей.
- Сетка: контейнер с боковыми отступами 20 px на телефоне, 40–64 px на
  десктопе; секции с большими вертикальными отступами (80–140 px).
- Декор: marquee-ленты, aurora-градиенты, точечные акценты acid. Декора много,
  но он всегда фоновый и не мешает чтению.
- Анимации — `framer-motion`, короткие (150–300 мс), с уважением к
  `prefers-reduced-motion` (см. `Reveal.tsx`, `MagneticButton.tsx`).

## 6. Компоненты и паттерны

- **Кнопка-акцент**: acid-фон, тёмный текст `ink`, pill, hover — лёгкий подъём
  и смена насыщенности; активная — без «прыжков» вёрстки.
- **Карточка**: `ink-soft` фон, 1 px `ink-line`, внутри — эйрбрау акцентом,
  заголовок Unbounded, текст Inter, `paper-dim`.
- **Заголовок секции**: `SectionHeading.tsx` — эйрбрау + крупный заголовок +
  короткий подзаголовок; повторять этот ритм, не изобретать новый.
- **Формы**: поля на `ink-soft` с границей, фокус — acid-обводка, ошибка — pink,
  подсказка — `paper-dim`; телефон — `shared/ui/PhoneField.tsx` с маской по стране.
- **Иконки**: `lucide-react`, размер 16–24, цвет — токен, не хардкод.
- **Медиа**: видео — `HeroVideo.tsx`, без автозвука, с постером; изображения —
  `loading="lazy"` ниже первого экрана.
- **Языки**: RU основной, EN — `/en`; тексты не хардкодим по месту, а держим в
  `site/src/data` (`content.ts` / `content.en.ts`) и в `shared/data`.

## 7. Админка (внутренние экраны)

- Светлая тема по умолчанию, тот же бренд: Unbounded + Inter, accent acid,
  палитра ink/paper.
- Плотнее, чем сайт: меньше воздуха, больше данных на экран; радиусы 10–12 px.
- Одна страница = один раздел; инлайн-стили постепенно убираются в `admin.css`
  (план — `DESIGN-IS-2026-10-20/05-redesign-plan.md`).
- Ссылки на ники, телефоны, почту — всегда кликабельные.
- `/admin`, `/book`, `/api` закрыты от индексации (`noindex`, `no-store`,
  `robots.txt`) — сохранять это при любых правках роутинга.

## 8. Тон и текст

- Русский — основной, живой, без канцелярита; английский — параллельный, не
  автоперевод.
- Заголовки короткие, в 3–6 слов; в тексте — конкретика (сроки, форматы,
  результат), без «инновационных решений».
- Эмодзи в интерфейсе не используем; в боте допустимы умеренно.
- Ошибки и пустые состояния — человеческим языком и с подсказкой, что делать.

## 9. Чек-лист перед пушем

1. Цвета и шрифты — только через токены; в обеих темах проверить.
2. Мобильный вид (380 px) и десктоп (1440 px) — без горизонтального скролла.
3. `prefers-reduced-motion` — анимации отключаются.
4. Контраст текста на фоне — не ниже 4.5:1 для основного текста.
5. Фокус с клавиатуры виден, aria-подписи у иконочных кнопок есть.
6. Новые строки — в оба языка (RU/EN), если это сайт.
7. `npx tsc -b`, `npm run build`, при необходимости — тесты раздела.
8. Ничего из «Правил владельца» (`HANDOFF.md`) не нарушено.
