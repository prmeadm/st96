# Карта проекта и правила размещения файлов

> Обновлено 2026-11-05. Правило одно: **файл лежит в папке того продукта, который
> его использует**. Если файл нужен двум продуктам — он идёт в `shared/`.

## Верхний уровень

| Папка / файл | Что это | Кто использует |
| --- | --- | --- |
| `site/` | сайт `st96.by`: `index.html`, `src/`, `public/`, `VISUAL-GUIDE.md` | сайт |
| `crm/` | CRM: `admin/` (админка `/admin`), `book/` (запись `/book`), `booking/`, `server/` (бот, заявки, воронки, рассылки, агент), `supabase/` (SQL), `prototypes/`, `docs/`, `VISUAL-GUIDE.md` | админка, бот, сервер |
| `api/` | функции Vercel (`/api/*`) — в корне, иначе Vercel их не находит | сайт + CRM |
| `shared/` | общее для сайта и CRM: `ui/` (`PhoneField`), `data/` (услуги, цели, политика, тексты EN) | сайт + CRM |
| `brand/` | бренд и печать: `avatar/`, `design-is-2026-10-14/` (аудит визиток), `print/` (в архиве на Диске) | вне сборки |
| `docs/` | `PLATFORM.md` (архитектура и статус), `DATABASE.md` (база), `STRUCTURE.md` (этот файл), `AUDIT-2026-10-31.md`, `TOOLING.md`, `VISUAL-GUIDE.md` (индекс гидов) | все |
| `scripts/` | служебные скрипты (прогоны воронки, graph-sections) | разработка |
| `dist/`, `node_modules/`, `graphify-out/` | артефакты: сборка, зависимости, граф кода | не редактировать руками |
| `CLAUDE.md`, `README.md`, `HANDOFF.md` | правила для агента, описание проекта, передача состояния | все |

## Правила

1. **Новый файл сайта** — в `site/src` или `site/public`. **CRM** — в `crm/`.
   **API-роут** — в `api/` (плоско, имя файла = путь `/api/<имя>`).
2. **Общий компонент или данные** (услуги, телефон, политика, RU/EN-тексты) —
   в `shared/`, не копировать в `site/` и `crm/`.
3. **Документ о дизайне интерфейса** — рядом с интерфейсом: гид сайта в `site/`,
   гид админки и `/book` в `crm/`. Общая бренд-основа — `docs/VISUAL-GUIDE.md`.
4. **Дизайн-аудит** — в папку продукта (`crm/docs/design-is-<дата>/`), аудит
   печати — в `brand/`.
5. **SQL-миграции** — только в `crm/supabase/migrations/` с порядковым номером;
   применённые миграции не переименовывать и не редактировать (история).
6. **Прототипы** — `crm/prototypes/<name>.html`, в сборку не входят.
7. **Печать и бренд** — `brand/`, в сборку Vercel не попадают.
8. Ничего нового в корне, кроме `README.md`, `CLAUDE.md`, `HANDOFF.md`,
   конфигов сборки (`package.json`, `tsconfig*.json`, `vite.config.ts`,
   `vercel.json`, `.oxlintrc.json`).

## Сборка и адреса

Одна сборка Vite (`vite.config.ts`) берёт три страницы: `site/index.html` →
`/`, `crm/admin/index.html` → `/admin`, `crm/book/index.html` → `/book`.
`api/` собирается Vercel отдельно. `brand/`, `docs/`, `crm/docs/`,
`crm/prototypes/` в прод не попадают.
