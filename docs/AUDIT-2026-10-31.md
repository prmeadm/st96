## Ошибки и риски (по приоритету)

1. **Секреты в исходниках деплоя `retouch-studio`.** В загруженных на Vercel
   исходниках лежит `.env` с живыми `GEMINI_API_KEY`, `ADMIN_PASSWORD`,
   `AUTH_SECRET`, `ACCESS_CODE`, `BLOB_READ_WRITE_TOKEN`. Публично файл не
   отдаётся (404 по `/` и `/src/`), но он виден в списке файлов деплоя.
   Действие: перевыпустить ключи, убрать `.env` из Vercel-деплоя
   (`.vercelignore`), убедиться, что ключи есть только в Environment Variables.
2. **Шрифты главной с Google Fonts.** `site/index.html` грузит Unbounded + Inter
   с `fonts.googleapis.com` (render-blocking CSS), хотя локальные `woff2` уже
   лежат в `site/public/fonts` и используются на `/book`. В RU это лишний
   внешний хост (медленно и нестабильно). Действие: перевести главную на
   локальные шрифты через `@font-face`, убрать `preconnect` и `<link>`.
3. **Project→repo связь только у `st96`.** Остальные три проекта задеплоены
   через CLI, код живёт только внутри деплоя. Пока это работает, но любая
   правка требует заново набирать исходники. Действие: завести репозитории
   (или положить `src/` в `prmeadm/st96` подпапками) и связать проекты с git.
4. **Двойной супервизор бота** (`deploy/…`/`bot/run.sh` — системный юнит) —
   известный хвост из `HANDOFF.md` платформы: systemd → `run.sh` → `main.py`.
   Действие: systemd сразу на `main.py`.
5. **Учёт ИИ-токенов неполный** — цена `gemini-3.1-flash-lite` подставлена
   оценкой; в аналитике это надо явно держать помеченным (уже помечено).
6. **Маска телефона** ломается на странах с разной длиной номера (Австрия).
7. **Google Meet** — одна общая комната на все встречи, нет учёта занятости.
8. **Галочка согласия на `/book`** отмечена по умолчанию — юридический риск
   (решение владельца, не менять без подтверждения).
9. **Тестовые данные в проде**: клиент `@studia96`, записи 20–22 октября.
10. **Шумное логирование** `tracedRepo` в серверном коде — мешает читать логи.

## Точки роста (что даст эффект)

1. **Скорость и вес главной**: локальные шрифты, `preload` для hero-медиа,
   проверка LCP на мобильном. Ожидаемо: минус один внешний хост и меньше
   блокирующих запросов.
2. **Конверсия заявки**: сейчас форма отправляет лид и редиректит в бота.
   Рост даст: сохранение введённого при ошибке, честное состояние «отправляю…»,
   повторная попытка без перезагрузки, разные сообщения для сайта/стенда.
3. **Воронки**: живой сквозной прогон (пункт 1 из `HANDOFF.md` платформы) —
   без него движок воронок не проверен в реальном сценарии с отложенным шагом.
4. **ИИ-консультант как узел воронки** + статистика воронок (пункт 2).
5. **Админка, фазы 3–4 редизайна**: общие `Modal`/`Seg`/`TemplatePicker`,
   вынос инлайн-стилей, фокус и клавиатура. План уже есть в
   `DESIGN-IS-2026-10-20/05-redesign-plan.md`.
6. **Медиа в блоке «Сообщение» воронки**: сейчас только ссылки — загрузка
   файлов и камера дадут полноценные сценарии.
7. **Уникальные комнаты Meet** через Google OAuth: убирает ручную работу и
   накладки со встречами.
8. **Памятка стенда и видео-страницы**: это витрины для показа клиенту —
   имеет смысл свести их к общему стилю из `docs/VISUAL-GUIDE.md` и добавить
   аналитику просмотров (сейчас не видно, что смотрят).
