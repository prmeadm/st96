## Что это
Собственная платформа вместо ChatPlace для студии ST96: Telegram-бот `@st96_leads_bot`, лиды и клиенты в Supabase, передача диалога человеку, админка `/admin`, воронки, рассылки, шаблоны, агент на бесплатной модели Gemini, запись на встречу `/book`, аналитика. Языки RU и EN. ChatPlace только эталон UX.

## Что готово и выложено (всё проверено на проде)
- **Бот и заявки:** вебхук, клиенты, согласие, `/start`, `/stop`, темы в группе «Лиды ST96», разбор заявок (сайт, стенд, группа), ручное добавление заявки текстом из Telegram, правка карандашом, удаление клиента и заявки, ссылки на ники/телефон/почту в админке.
- **Воронки:** движок и визуальный конструктор (на весь экран), блок «Запись на встречу», условия и действия, задержки через pg_cron.
- **Рассылки и шаблоны:** рассылки с медиа и сегментами, шаблоны с фото, видео (камера устройства), голосом, фильтрами и рейтингом популярности.
- **Агент:** задания с согласованием плана, импорт клиентов из экспорта группы, выбор модели и своих моделей, перевод на английский (Gemini).
- **Услуги только с сайта:** `crm/server/catalog.ts` строится из `shared/data/services.ts` и `content.en.ts`; старые услуги остались только в истории заявок.
- **Запись на встречу `/book`:** общее расписание, порядок «формат, день и время, услуга (с пунктами), контакты», маска телефона по стране (по IP), подстановка контактов клиента по личной ссылке `?c=`, кнопка «Из Telegram» (бот по токену), цель встречи списком, общая ссылка Google Meet, заявка лично администратору (@studia96 по умолчанию) с кнопками решения, календарь по услугам и выходным в админке, бронирование слота из админки.
- **Аналитика:** токены и деньги (эквивалент платного тарифа) по моделям и функциям, события шаблонов, период на выбор.
- **Админка:** светлая, бренд Unbounded + Inter, акцент acid `#d8ff3f`; уведомление «Вышла новая версия» для устаревших вкладок.

## Как запустить и проверить
- `npm install`, `npm run dev` (сайт), сборка `npm run build`.
- Типы: `npx tsc -b` и `npx tsc -p tsconfig.node.json --noEmit`.
- Тесты серверной логики: 117 проходят. Общий `npm run test:server` может зависнуть, надёжнее по файлам: `npx tsx --test crm/server/booking/booking.test.ts` и так далее (`agent`, `bot`, `funnels/engine`, `leads/*`, `broadcasts`, `translate`, `usage`).
- Деплой: пуш в `main` = прод на Vercel (`prmeadm/st96`). Каждый пуш согласовывался с владельцем отдельно.
- Миграции Supabase (ref `ljatihrxiuouukakbdtb`) `0001`–`0011` применены; новые применяются вручную в SQL-редакторе (владелец сам входит в Supabase во встроенном браузере).
- Граф кода: перед вопросом по коду `graphify query "<вопрос>"`, после правок `graphify update .`.

## Секреты (только в Vercel, в код и чат не попадают)
`TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `TELEGRAM_WEBHOOK_SECRET`, `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, `INGEST_SECRET`, `LLM_API_KEY` (`LLM_BASE_URL`, `LLM_MODEL` необязательны, свои модели `LLM_KEY_*`), реклама: `META_*`, `TIKTOK_*`. ## Известные ограничения и хвосты
- **Камера iPhone в Safari:** Safari отдаёт сайту одну камеру, выбирает её macOS; в окне «Снять» есть подсказки и диагностика. Программно переключить нельзя (Chrome показывает список).
- **Google Meet:** одна общая комната на все видеозвонки (`booking_meet_default`); уникальная комната на встречу и учёт занятости из Google Calendar требуют OAuth (не сделано).
- **Токены ИИ:** учёт идёт с 2026-10-20; у `gemini-3.1-flash-lite` цена на странице Google не опубликована, подставлена как у 3.5 Flash-Lite (помечена оценкой, редактируется в «Аналитике»).
- **Маска телефона:** лимит цифр по длине мобильного номера страны; у стран с разной длиной (например Австрия) может быть короче реального.
- **Галочка согласия на /book** отмечена по умолчанию по просьбе владельца; по GDPR и закону о персональных данных обычно нужно активное согласие, решение за владельцем.
- Главный сайт `st96.by` всё ещё берёт шрифты у Google Fonts (на `/book` они свои, `site/public/fonts`).
- Тестовые данные в базе: клиент `@studia96` (аккаунт владельца), тестовые записи на 20–22 октября (в том числе отменённые).
- Шумное логирование `tracedRepo` можно убрать.
