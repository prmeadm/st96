# Бренд ST96 (brand/)

Фирменные материалы и печать. В сборку сайта и CRM не входят, не деплоятся.

- `avatar/` — фирменные аватары ST96 (SVG, PNG) и скрипт сборки `avatar/build.mjs`. В git.
- `design-is-2026-10-14/` — дизайн-аудит визиток 90×50 (scope → evidence → scorecard → verdict → handoff).
- `print/` — визитки и флаер A6, перенесены в Google Диск: `Мой диск/Архив Mac/st96-print-<дата>.tar`.
  Локально папки нет. Восстановление: `cd brand && tar xf "<путь к архиву>"`.
- Скриншоты стороннего проекта `screens-b-leasing/` удалены по решению владельца.

Скрипт аватаров берёт шрифт и библиотеки из `print/business-cards`, поэтому для его запуска
сначала восстановите `print/` из архива.

Визуальные правила бренда — в `docs/VISUAL-GUIDE.md` (общая основа) и в гидах
`site/VISUAL-GUIDE.md`, `crm/VISUAL-GUIDE.md`.
