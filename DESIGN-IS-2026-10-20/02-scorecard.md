# Scorecard (10 принципов Рамса)
1. Инновационный — 2/3. Визуальный конструктор воронок и шаблоны в одной системе: улучшение известных паттернов.
2. Полезный — 2/3. Основные задачи выполняются, но отправка шаблона = 5 действий (карточка → выбрать → шаблон → предпросмотр → отправить); карточка клиента длинная.
3. Эстетичный — 1/3. Система токенов есть, но 59 инлайн-стилей, 11 размеров шрифта, дубли стилей модалок, захардкоженные цвета, невидимое кольцо фокуса.
4. Понятный — 2/3. Подписи понятны; «JSON», эмодзи вместо иконок, смесь «Заявки/Заметки/Шаблоны» без пояснений.
5. Ненавязчивый — 2/3. Интерфейс тихий, но карточки с тенью на каждом блоке.
6. Честный — 1/3. FunnelsPage.tsx:29 обещает то, что уже есть (ложная подсказка); при равенстве взят меньший балл.
7. Долговечный — 2/3. Скруглённые карточки с мягкой тенью и эмодзи-навигация — признаки текущей моды.
8. Аккуратный до мелочей — 1/3. Нет :focus-visible, модалки без dialog/Escape, разные формы подтверждения успеха.
9. Экономный — 1/3. ≈740 КБ JS на любой странице админки (React Flow грузится и для списка клиентов); тема и покой по анимациям в порядке.
10. Как можно меньше дизайна — 2/3. ≤2 лишних элемента, но три копии выбора шаблона и две копии стилей модалки.
**Итого: 16/30.** Нулей нет.
