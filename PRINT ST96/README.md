# PRINT ST96

Отдельный подпроект: печатная продукция и фирменные материалы ST96. Никак не связан с сайтом и CRM: не входит в сборку, не деплоится.

- `brand/` фирменные аватары ST96 (SVG, PNG) и скрипт сборки `brand/avatar/build.mjs`. В git.
- `print/` визитки и флаер A6 перенесены в Google Диск: `Мой диск/Архив Mac/st96-print-<дата>.tar`. Локально папки нет. Восстановление: `cd "PRINT ST96" && tar xf "<путь к архиву>"`.
- `screens-b-leasing/` удалён (скриншоты стороннего проекта, по решению владельца).

Скрипт аватаров берёт шрифт и библиотеки из `print/business-cards`, поэтому для его запуска сначала восстановите `print/` из архива.
