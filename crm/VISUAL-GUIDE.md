# CRM ST96 — визуальный гид

> Относится к админке `/admin` и записи на встречу `/book` (папка `crm/`).
> Сайт `st96.by` — в [`site/VISUAL-GUIDE.md`](../site/VISUAL-GUIDE.md), общая
> основа бренда — [`docs/VISUAL-GUIDE.md`](../docs/VISUAL-GUIDE.md).

CRM — рабочий инструмент: здесь важнее плотность и читаемость, чем витрина.
Бренд тот же (Unbounded + Inter, acid, ink/paper), но интерфейсы разные:
админка светлая, запись на встречу тёмная — как сайт.

## 1. Источник правды

| Что | Где |
| --- | --- |
| Токены админки (светлая тема, единственная) | `crm/admin/admin.css` (`:root`) |
| Токены `/book` (тёмная тема, как сайт) | `crm/book/book.css`, `crm/book/fonts.css` |
| Общие UI-компоненты | `crm/admin/ui/`, `shared/ui/PhoneField.tsx` |
| Календарь записи | `crm/booking/MonthGrid.tsx`, `crm/booking/monthgrid.css` |
| Прототип (для сверки UX, не в сборке) | `crm/prototypes/admin-v1.html` |
| План редизайна админки | `crm/docs/design-is-2026-10-20/05-redesign-plan.md` |

Правило: новый цвет, шрифт или радиус **не вводим**. Нужного не хватает →
сначала добавить токен в `admin.css` (или `book.css`), потом использовать.

## 2. Админка: палитра (светлая, единственная)

| Токен | Значение | Роль |
| --- | --- | --- |
| `--bg` | `#f4f6fb` | фон приложения (мягкий холодный) |
| `--card` | `#ffffff` | карточки, панели, sidebar |
| `--ink` | `#232a3b` | основной текст |
| `--mute` | `#5f6980` | вторичный текст, подписи |
| `--line` | `#e6e9f2` | границы, разделители |
| `--line-strong` | `#7d879f` | границы полей ввода |
| `--accent` | `#d8ff3f` | acid: заливка кнопок и активных пунктов, текст на нём — `--on-accent #09090b` |
| `--accent-soft` / `--accent-edge` | `#f1fbc8` / `#b3d414` | активный пункт навигации, мягкие плашки |
| `--blue` | `#2f55d4` | ссылки (единственный «синий ссылки») |
| `--green` / `--amber` / `--red` | `#0f7a4d` / `#9a5700` / `#b52a31` | статусы: успех / внимание / ошибка |
| `--violet` / `--teal` | `#6a45e0` / `#08717d` | служебные категории, заметки |
| `--mark` | `#fbf3a6` | подсветка поиска |

Брендовые `--brand-ink #09090b`, `--brand-paper #f5f4ef`, `--brand-acid #d8ff3f`
используются точечно: логотип-«таблетка» в sidebar, акцентные элементы.

Правила:
- **Тёмной темы в админке нет** — решение владельца (2026-10-20): глаза не должны
  уставать; dark-acid остаётся за сайтом.
- Acid на светлом **не годится как цвет текста** — только заливка с тёмным текстом.
- Синий — только для ссылок; статусы — только из зелёного/жёлтого/красного набора.

## 3. `/book`: палитра (тёмная, как сайт)

| Токен | Значение | Роль |
| --- | --- | --- |
| `--bg` | `#09090b` | фон |
| `--card` | `#111114` | карточки |
| `--line` | `#232328` | границы |
| `--ink` | `#f5f4ef` | текст |
| `--dim` / `--mg-mute` | `#a6a6ac` | вторичный текст |
| `--acid` | `#d8ff3f` | CTA, выбранный слот, чекбокс |
| `--red` | `#ff7a7f` | ошибки формы |
| `--mg-*` | — | состояния календаря: открыт / закрыт / выбран / hover |

Правила: кнопки и выбранные чипы — acid с тёмным текстом; поля — `--bg` с
границей `#34343a`; фокус — acid-обводка 2 px.

## 4. Типографика и размеры

- `--font-display: "Unbounded", "Inter", system-ui, sans-serif` — заголовки,
  логотип, крупные цифры.
- `--font-body: "Inter", system-ui, -apple-system, "Segoe UI", sans-serif` — всё остальное.
- Шкала админки: `--fs-xs 12`, `--fs-sm 13`, `--fs-md 14` (базовый), `--fs-lg 16`,
  `--fs-xl 20`, `--fs-2xl 24`.
- Отступы: `--s-1 4`, `--s-2 8`, `--s-3 12`, `--s-4 16`, `--s-5 24`, `--s-6 32`.

## 5. Форма и ритм админки

- Плотнее сайта: меньше воздуха, больше данных на экран; радиусы 10–12 px
  (карточки 10, поля 10, кнопки 10 / pill для чипов).
- Sidebar: 220 px, при сворачивании 68 px, иконки тонкие линейные
  (`crm/admin/ui/Icon.tsx`), активный пункт — `--accent-soft` + `inset 0 0 0 1px --accent-edge`.
- Тени мягкие, из токенов `--shadow`, `--shadow-sm`, `--shadow-lg`; hover — не
  двигает вёрстку.
- Одна страница = один раздел; инлайн-стили постепенно убираются в `admin.css`
  (план — `crm/docs/design-is-2026-10-20/05-redesign-plan.md`).
- Фокус: `:focus-visible` — 2 px `--focus` с отступом 2 px; поля — смена границы.

## 6. Паттерны CRM

- **Кнопка**: primary — acid-заливка, тёмный текст; secondary — белая с
  `--line-strong`; danger — красный текст на `--red-soft`.
- **Карточка/секция**: `--card`, 1 px `--line`, `--shadow-sm`, заголовок
  Unbounded 16–20.
- **Таблица/список**: строки разделяются `--line`, hover — `--bg`; данные
  моноширинно не набираем, только Inter.
- **Ссылки на данные**: ники Telegram, телефоны, почта — всегда кликабельные.
- **Статусы**: бейдж = цвет статуса + `-soft` фон + тёмный текст.
- **Пустые состояния**: человеческим текстом + одно действие.
- **Модальные окна**: общий `Modal`, оверлей `--overlay`, фокус-ловушка,
  закрытие Esc (фаза 2 редизайна).
- **Иконки**: `lucide-react`, 16–24, цвет — токен.

## 7. Тон и текст

- Русский, живой, без канцелярита; английский — параллельный.
- Эмодзи в интерфейсе не используем.
- Ошибки — что случилось и что сделать; никаких кодов и стектрейсов в лицо.

## 8. Доступ и индексация

- `/admin`, `/book`, `/api` закрыты от индексации (`noindex`, `no-store`,
  `robots.txt`) — сохранять при любых правках роутинга и заголовков.
- Вход в админку — только владелец, через Supabase Auth; пароли и ключи в
  интерфейсе не показываем и не просим.

## 9. Чек-лист перед пушем (CRM)

1. Цвета и шрифты — только через токены `admin.css` / `book.css`.
2. Мобильный вид (380 px) и десктоп (1440 px): sidebar, таблицы, модалки —
   без горизонтального скролла и обрезанных кнопок.
3. Фокус с клавиатуры виден на всех интерактивных элементах.
4. Ссылки на ники/телефоны/почту кликабельные.
5. `npx tsc -b`, тесты раздела (`crm/server/**/*.test.ts`).
6. Ничего из «Правил владельца» (`HANDOFF.md`) не нарушено.
